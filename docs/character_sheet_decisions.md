# Character Profile

## Character Identity
the identity section of the character sheet or the character profile section of settings will contain the following fields, all required:
- character name
- class & level
- race
- alignment
- background

## Character Basics
- armor class
- initiative
- speed
- current hit points
- max hp
- hit dice (dependent on class)

## Abilities
5e srd, point buy system

## Skills
5e srd

# Available Actions/Bonus Actions/Reactions
- number of actions remaining this round
- number of reactions remaining this round
player gets 2 actions, 1 bonus action, and 1 reaction per turn in battle. certain classes or skills may add additional actions or reactions per turn. that may be on the first round of every combat, on every round of every combat, or a set number of extra actions/reactions per long rest.

## Weapons
each currently equipped weapon appears in this section.
- weapon (name)
- attack bonus
- damage
- crit
- hand (main-hand, off-hand, two-hand)
- swap weapon (in combat this costs 1 action. outside of combat it's free)

## Spells
5e srd
- concentrating (yes/no is the character currently concentrating on something. if yes then other concentration spells are not available unless you end the current concentration)
- end current concentration

each currently equipped spell appears here.
- spell (name)
- attack (if applicable)
- effect (damage or condition or whatever is applicable)
- concentration (yes/no does the spell require concentration)
- view details (spell card)

## Special
if a skill or other specialty thing has an action/reaction available but is not a spell or a weapon it's listed here.
- name
- view details (skill/ability/feat card. note: feats are a future feature, not shipping with v1)
